## Note1
- The purpose of `example1.sh` and `example2.sh` is to create the build, compile and execute `example1.cpp` and `example2.cpp` automatically.

- Use `clean.sh` to clean the build after using it.



## Note2
If you have any problems with the permission, execute:

``` [bash]
chmod +x example1.sh && chmod +x example2.sh && chmod +x clean.sh
```
