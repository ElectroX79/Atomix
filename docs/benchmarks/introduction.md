# Benchmarks

This section is dedicated to benchmarks, there are two types of benchmarks:
- **Internals**: these benchmarks are used to evaluate and compare between two candidates 
or versions of Atomix and help to take decisions.
- **Externals**: comparison of Atomix with an external reference 
(custom external script, commercial products ...)
