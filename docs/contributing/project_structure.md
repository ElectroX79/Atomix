
# Project Structure

Atomix is organized into several directories, each with a specific purpose.

```text
Atomix/
├── include/            # Public and internal headers
├── src/                # Implementation
├── test/               # Tests
    ├── benchmark/      # Benchmarking
    ├── component_test  # Integrity tests
├── scripts/            # Scripts
├── docs/               # Documentation
```
