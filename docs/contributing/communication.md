## Communication

Atomix uses different GitHub tools depending on the type of communication.

### Issue

Use an **Issue** when you have:

* a question about the project;
* a proposal or feature idea;
* a bug report;
* a correction;
* a problem that should be tracked.

For large proposals, you may open a Pull Request with a document in the documentation instead. This depends on the size and complexity of the proposal.

### Discussion

Use a **Discussion** when you want to raise a concern, start a broader conversation, or give feedback without a specific solution.

Discussions are useful when the goal is to discuss a problem before deciding what should be done.

### Pull Request

Use a **Pull Request** when you have an actual change to the repository.

A Pull Request can also be used for a large proposal when the proposal is easier to review as a document or other repository change.

### Response time

We try to respond to Issues, Discussions and Pull Requests within a reasonable amount of time.
When a response may take longer, we may leave a short comment to let contributors know that the issue has been seen.


---
Note: When in doubt, start with an Issue or Discussion. It is always possible to move the conversation later.
