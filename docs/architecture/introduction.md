# Introduction to the Architecture

This section provides an overview of Atomix's internal architecture.

Instead of focusing on implementation details, it explains the role and responsibilities of each subsystem, how they interact, and the design decisions behind them. Once these concepts are understood, the implementation details become much easier to follow.

For implemented architecture, the following sections are:

- [Memory management](mem_management.md): explains the memory management subsystem.
- [Data table](data_table.md): how the columnar relational data table is implemented.

But if you want to learn more about future implementations, go to [future features](fu).
