# Welcome to Atomix

## What is Atomix?

Atomix is an experimental analytical data engine. Its goal is to achieve high data throughput and efficient dataset processing,
exploring different approaches to data processing and storage.

## Who is this documentation for?

- Developers who want to learn more about Atomix.
- Potential and current contributors of Atomix.
- Potential users of Atomix.

## Organization

The project structure is composed of the following sections:

- [Getting Started](getting-started/introduction.md): Useful to find information about how to get started with Atomix.

- [Architecture](architecture/introduction.md): To understand how Atomix is structured and how it works.
- [Internals](internals/introduction.md): Where you can find information about the internal design of Atomix.

- [Benchmarks](benchmarks/introduction.md): A section dedicated to put numeric proof of the performance, usually quoted from other pages to validate some decisions.
- [Future features](future_features/introduction.md): To consult features that could be added in the future.

- [Contributing](contributing/introduction.md): If you want to contribute to Atomix.
